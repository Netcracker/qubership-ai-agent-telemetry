## Skill trigger: `ai-agent-telemetry-configure`

When setting up, checking, or repairing machine-wide AI agent telemetry, invoke the
`ai-agent-telemetry-configure` skill. Use it after CLI installation, when global hook status is
missing or invalid, when events do not reach the collector, or when the user asks whether
telemetry is working.
