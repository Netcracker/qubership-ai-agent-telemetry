# CLI help implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add discoverable, side-effect-free help for every public CLI command without adding a CLI framework.

**Architecture:** Add `help.go` as the centralized catalog and formatter for command names, descriptions, usage, and
options. Keep command execution in the existing `run` switch, with a small routing preamble for explicit help and
relevant usage appended to command-line errors.

**Tech Stack:** Go standard library, existing `run` unit-test seam, and Markdown documentation.

## Global constraints

- Do not add a CLI framework or another dependency.
- Support `help`, `-h`, and `--help` at the root and command levels.
- Keep explicit help side-effect free and return exit code 0.
- Keep invalid command lines at exit code 2 and preserve hook-safe `ingest` failures at exit code 0.
- Store public command metadata and help text in one catalog.

- [ ] **Step 1: Write failing table-driven tests for root and command help**

Add tests that exercise the real `run` dispatcher:

```go
func TestRunHelp(t *testing.T) {
    tests := []struct {
        name string
        args []string
        want string
    }{
        {name: "help", args: []string{"help"}, want: "Commands:"},
        {name: "short flag", args: []string{"-h"}, want: "Commands:"},
        {name: "long flag", args: []string{"--help"}, want: "Commands:"},
        {name: "help topic", args: []string{"help", "hooks"}, want: "ai-agent-telemetry hooks install"},
        {name: "command help", args: []string{"hooks", "help"}, want: "--target=<list>"},
        {name: "command short flag", args: []string{"configure", "-h"}, want: "--hooks=<targets>"},
        {name: "command long flag", args: []string{"status", "--help"}, want: "--verbose"},
        {name: "nested action help", args: []string{"hooks", "install", "--help"}, want: "--target=<list>"},
    }
    for _, tt := range tests {
        t.Run(tt.name, func(t *testing.T) {
            var out string
            if code := run(tt.args, func(s string) { out += s }); code != 0 {
                t.Fatalf("exit code = %d, want 0; output = %q", code, out)
            }
            if !strings.Contains(out, tt.want) {
                t.Fatalf("output = %q, want %q", out, tt.want)
            }
        })
    }
}
```

Add a loop over all cataloged public commands, and verify that every command supports `help`, `-h`, and `--help`.
Isolate `HOME`, `XDG_CONFIG_HOME`, and `XDG_CACHE_HOME`, then verify help creates no files. Add error cases for no
arguments, `help unknown`, `help hooks extra`, an unknown root command, and incomplete `hooks`.

- [ ] **Step 3: Add the centralized command catalog and formatters**

Create `help.go` with one `commandHelpEntry` slice in display order. Each entry contains the command name, summary,
usage lines, and option descriptions. Format root and command help from this catalog. Add small predicates for root help
tokens and the supported command-level positions; do not scan arbitrary trailing arguments.

The catalog must cover:

```text
configure
hooks
status
selftest
ingest
flush
update-check
self-update
version
```

Document accepted hook targets accurately: `configure --hooks=<targets>` accepts `all`, `none`, or a comma-separated
subset of `claude`, `codex`, and `cursor`; `hooks install --target=<list>` defaults to all three and accepts only a
comma-separated harness list.

- [ ] **Step 4: Route help before executing commands**

Update the start of `run` so no-argument and unknown-command failures include `rootHelp()`. Handle `help <command>` and
the two help flags before entering the execution switch. For known commands, handle `<command> help`, `<command> -h`,
and `<command> --help`; additionally handle `hooks install help|-h|--help`.

When `parseHooksCommand` reports an error, print the error followed by the `hooks` help. Keep code 2. Do not change
`parseIngestFlags` or the hook-safe return code on ingest parsing failures.
